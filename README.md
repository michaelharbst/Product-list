# Product list

This application is a very basic way to enter products into - not a database - but the ram, so everything is gone once you exit the application. It is the first mini project in a developer course, so it is really very basic. I used around 1 day on it and most of the time used was to figure out how regex works.
It is made in c# and is a pure console application. I split it into two files that was probably overdoing it. Since there is only one inventory list I made everything static. Really there is not much more to say except that there is a lot of potential for improvement.
